# Task 3 – SQL for Data Analysis

## Objective

The objective of this task is to use SQL queries to extract and analyze structured e-commerce data.

## Dataset

The dataset used for this task is an e-commerce sales dataset containing order, customer, location, product, sales, cost, profit and quantity information.

## Tools Used

* SQLite
* DB Browser for SQLite
* VS Code
* GitHub

## SQL Concepts Implemented

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* SUM()
* AVG()
* Subqueries
* INNER JOIN
* LEFT JOIN
* Views
* Indexes

## Analysis Performed

The analysis includes:

1. Retrieving order and sales information.
2. Filtering high-value sales.
3. Sorting orders by sales.
4. Calculating total sales by category.
5. Calculating total and average sales and profit.
6. Analyzing sales and profit by region.
7. Calculating revenue per customer.
8. Calculating average revenue per user.
9. Performing INNER JOIN and LEFT JOIN operations.
10. Creating a view for category-level analysis.
11. Creating indexes to improve query performance.

## Files

* `ecommerce_analysis.sql` – SQL queries used for analysis.
* `ecommerce_dataset.csv` – Dataset used for the task.
* `screenshots/` – Screenshots showing SQL queries and their outputs.

## Outcome

The task demonstrates the use of SQL for manipulating, querying and analyzing structured e-commerce data.
